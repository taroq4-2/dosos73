# dosos73 1.3.1

The signed 1.3.1 APK is 58,885,174 bytes and supports Android 10 and newer on ARM64, ARM32, x86, and x86_64. It uses the existing signing certificate. Build verification passed 126 JVM tests and 48 packaging-tool tests, Android Lint, signature checks, and alignment checks. Repacking preserved the 608 native binaries and all 1,863 runtime archive entries byte for byte after decompression.

حجم الحزمة الموقّعة 58,885,174 بايت. تدعم أندرويد 10 فأحدث وتضم المعماريات الأربع في ملف واحد. اجتازت اختبارات المشروع وفحوص التوقيع والمحاذاة. يعمل المشغّل من التخزين المحلي، ويستمر صوت المقطع عند مغادرة واجهة التطبيق. قياس استهلاك البطارية والتحقق من سلوك التشغيل على الأجهزة الفعلية قيد الاختبار.

The public APK passed install and launch on Android 15. The Arabic and English captures are from that exact APK. Both local playback instrumentation cases passed on API 35 in the source verification job. Three download UI cases failed in that same job.
