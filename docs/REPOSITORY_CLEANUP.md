# Current-release repository policy

The public download page presents one current universal release. Superseded APKs, release assets and release tags are removed only after the replacement is published, downloaded again and verified against its signed checksum. The current tree contains current screenshots, source/build scripts, tests, license notices and release evidence. Older generated inventories and phase-specific release reports are removed; Git source history is preserved.

No user media, signing material or local emulator data is part of repository cleanup. The release contains one installable APK; separate source archives, checksums and SBOM support verification and source access.
