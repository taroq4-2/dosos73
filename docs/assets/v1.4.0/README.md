# dosos73 1.4.0 images

Every phone screen in these images is an unedited screenshot of the dosos73 1.4.0 release build (debug-key signed for installation) on the `dosos73_vnext` Android 15 emulator, 1080 × 2400, taken on 21 November 2026.

- The status bar uses Android's demo mode (fixed 12:00 clock, full battery, no notification icons).
- The downloads are real transfers: the dosos73 1.3.2 APK from GitHub, the F-Droid client from f-droid.org, and *Big Buck Bunny* (© Blender Foundation, CC BY 3.0) from its official upload. Nothing in the screens was staged or edited.
- The "Waiting for permitted network" screen was taken with airplane mode turned on during a real download.
- Frames, backgrounds and captions were composed with HTML and rendered with headless Chrome. The Tajawal font is under the SIL Open Font License.
