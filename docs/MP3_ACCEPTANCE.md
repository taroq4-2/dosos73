# MP3 output

The universal release bundles FFmpeg9.0.2 and LAME3.100 for local MP3 V0 conversion. No separate audio engine is downloaded after pasting a link. Converted choices have unknown final size/bitrate rather than inheriting the source values; an unchanged source MP3 can retain Original labeling.

Acceptance uses a real YouTube link, actual conversion and saved MediaStore audio/mpeg bytes. The current artifact identity, byte count, hash and playback evidence are recorded in [verification](VERIFICATION.md). Unit tests distinguish original MP3 from converted formats; device tests run the bundled encoder. V0 is variable-bitrate encoding and cannot improve the source's quality.

Native extraction can restart after interruption. Login-only, private, DRM or unavailable source content is not bypassed. The output size depends on duration and content, rather than a fixed app download limit.
